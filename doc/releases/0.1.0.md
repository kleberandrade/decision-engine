# decision_engine 0.1.0 — release candidate

This is the initial weighted-sum/TOPSIS baseline on local `main`. It is not
published or tagged. AHP is developed separately on `feat/ahp` as 0.2.0-dev.1.

## Included behavior

- Pure Dart multicriteria ranking with no runtime dependencies.
- Direction-aware weighted sum and vector-normalized TOPSIS.
- Inclusive minimum/maximum constraints applied before normalization.
- Immutable rankings, exact ties, complete exclusion reasons and numeric traces.
- Typed public extension contracts, English/Portuguese guides and MIT license.

## Validation status

The baseline passed 27 public-API tests, strict analysis and three Dart examples.
The provider example was also compiled to JavaScript and executed with Node.
Flutter static analysis passed for the source-consumer fixture. Its widget tests
could not start because local socket binding is restricted in this session.
Minimum SDK 3.3.0 validation and full remote CI remain pending. Publication dry-run
could not finish online dependency resolution. These pending checks must pass
before publication; this document is not evidence of a completed release.
