# decision_engine 0.2.0

Adds AHP criterion weighting to the pure Dart multicriteria decision engine.
The 0.1.0 weighted-sum/TOPSIS APIs remain compatible. No runtime dependencies,
Flutter imports, HTTP services or network calls are added to the core.

## New behavior

- Derive principal-eigenvector weights from 1–10 pairwise criterion comparisons.
- Validate finite values on [1/9, 9], diagonal unity and reciprocal judgments.
- Inspect immutable weights, lambdaMax, CI, RI, CR, iterations and residual.
- Convert weights to directed criteria for weighted sum or TOPSIS.
- Reject inconsistent weights during conversion by default; explicit opt-in is
  available after inspecting the evidence.

The RI table, numerical tolerances, inclusive CR threshold and convergence budget
are documented in English and Portuguese. This implements criterion weighting,
not full hierarchical AHP synthesis. Run `dart run example/ahp.dart`.
