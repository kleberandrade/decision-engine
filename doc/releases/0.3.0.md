# decision_engine 0.3.0

Adds weight sensitivity and an optional Flutter laboratory. The core remains
pure Dart, with no runtime dependencies, Flutter imports, server or HTTP API.
Existing 0.2.0 ranking and AHP APIs remain compatible.

## New behavior

- Complete relative-weight scenarios and normalized one-criterion sweeps.
- Complementary weights retain baseline proportions; no uniform fallback is
  invented for zero complementary mass.
- Compare full winner sets, including ties, and inspect competition-rank changes,
  maximum normalized-weight changes and the full calculation trace per scenario.
- Report sampled winner-set stability and adjacent transition brackets.
- Explore relative weights, AHP, weighted sum/TOPSIS, sampled curves and matrices
  in a separate Flutter example package with responsive layouts.

A sampled transition is not an exact crossing point. Sample stability is not a
probability or a continuous robustness guarantee. See the English/Portuguese
sensitivity guide and `example/sensitivity.dart`.

## Validation and release gates

The development CI passed Dart 3.3.0, stable Dart and the Flutter source consumer,
but initially failed the lab widget suite with a 38-pixel dropdown overflow.
That failure was reproduced using Ahem test fonts and corrected by expanding the
dropdowns within available width. The native render smoke then passed with Ahem.

Run the final CI on this release candidate, including all 52 core tests, the
Flutter consumer, the four lab widget tests, web build and publication dry-run.
Only then publish 0.3.0 and create the v0.3.0 source tag/release. This notes file
does not claim that the candidate is already published.
